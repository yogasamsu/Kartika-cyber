**buatan** untuk demo ringkasan kerentanan. CVE-nya nyata, tetapi pemetaan ke
host lab dan versi paketnya contoh, bukan hasil pemindaian lab.

```bash
python3 -m tameng --kerentanan lab/sample/kerentanan-alerts.json
```
